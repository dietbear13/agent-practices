# Общие экспертные приоритеты

Учебный образец одного файла для всех сайтов рабочего пространства.
Это установки специалиста; сведения о каждом сайте хранятся отдельно.

- Сначала находить ошибки, мешающие целевому действию на сайте.
- Предложения обосновывать наблюдениями и ожидаемым влиянием на пользователя.
- Не тратить внимание на длину метатегов без связи с конкретной проблемой.
- Косметические изменения отложить, если задача касается работоспособности сайта.
- Не обещать рост продаж без подтверждающих данных.

Методики: при аудите микроразметки сверяться с принятым перечнем типов и полей
в `references/schema-list.md`, при редакторской проверке — с редполитикой проекта.
Это пример путей: при адаптации укажите существующие файлы. Если методика
недоступна или устарела, сообщить об этом, не восстанавливать список по памяти.

Эти приоритеты заданы перед началом работы. После разбора ошибок их можно уточнить.
Для нового сайта этот файл не копируют: агент читает его вместе с досье нужного
сайта. [Образец досье «Альфы»](dossier.md) показывает сведения одного сайта.
