# Шесть практик для работы с агентами

Практическое руководство к докладу
[«Как и из чего собирать ИИ-агентов, чтобы это не было похоже на гадание»](https://docs.google.com/presentation/d/19Km9pqSWkO8MYYQy6hK6UV9t7NFOYNlEDYHKxAOlIKQ).
Дайте ссылку
своему агенту: он сравнит практики с вашим проектом и предложит конкретные улучшения.
Установка, Python, MCP и поддержка субагентов для этого не нужны.
Примеры служат материалом для адаптации, а не обязательным комплектом файлов.
Общие приоритеты относятся ко всем сайтам пространства; досье и данные выбираются
для конкретного сайта. Существующие файлы и пути сохраняются.

Стартовый промпт:

```text
Прочитай https://github.com/dietbear13/agent-practices/blob/main/AGENT-GUIDE.md.
Сравни шесть практик с моим проектом по доступным файлам. Покажи находки
с доказательствами и предложи минимальные изменения. Сейчас нужен только разбор.
```

Начните с [руководства для агента](AGENT-GUIDE.md).

Для сопровождающих: `python run_tests.py -v` проверяет внутренние ссылки,
навигацию и образец gitignore для обеих структур. Нужны Python и Git,
дополнительные пакеты Python не требуются.
Основания переноса содержания перечислены в [сверке с докладом](docs/source-review.md).
