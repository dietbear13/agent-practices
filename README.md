# Как улучшить своего агента: практики из доклада

Материалы к докладу «Как и из чего собирать ИИ-агентов, чтобы не стрелять из пушки по
воробью и не попасть себе в ногу». Здесь ничего не нужно устанавливать: вы даёте
ссылку своему агенту, он сравнивает вашу настройку с практиками из доклада и
предлагает несколько точечных правок в ваших же файлах.

## Как пользоваться

Откройте своего агента (Claude Code, Codex или другого) в папке проекта и вставьте:

```
Изучи https://github.com/dietbear13/agent-practices/blob/main/AGENT-GUIDE.md и действуй по нему:
сравни мою текущую настройку агента с практиками оттуда и предложи, что улучшить.
Ничего не меняй без моего согласия.
```

Что будет дальше:

1. Агент прочитает ваши файлы правил, скиллы, подключённые MCP, `.gitignore`. Ключи
   из `.env` он не открывает.
2. Покажет таблицу: какие практики у вас уже есть, каких нет, и на чём основан вывод.
3. Задаст до семи вопросов и перечислит, что он предположил по умолчанию.
4. Предложит 3–5 правок — с объяснением, что каждая чинит и сколько стоит.
5. Применит только те, на которые вы согласитесь, по одной.

## Без агента

- [CHEATSHEET.md](CHEATSHEET.md) — четыре промпта с финального слайда. Работают сразу,
  без всякой настройки.
- [TALK.md](TALK.md) — тезисы доклада по разделам.
- Практики по отдельности — в `blocks/core/*/README.md`; список — в
  [AGENT-GUIDE.md](AGENT-GUIDE.md#шаг-2-сверка-с-практиками).

## Если агента ещё нет

Можно собрать минимальный каркас с нуля: агент задаст до шести вопросов и разложит
файлы по ответам. Для этого репозиторий нужно клонировать, нужен Python 3.9+ —
подробности в [brief/HOWTO.md](brief/HOWTO.md).

## Для тех, кто правит этот репозиторий

```
python run_tests.py                  # тесты, только стандартная библиотека
python bootstrap/catalog.py --build  # пересобрать catalog.json после правки блоков
```
