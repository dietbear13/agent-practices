# Адаптация чужого

**Ничего чужого не ставится как есть.** Между «нашёл на гитхабе» и «работает у
меня» — аудит и несколько вопросов. Пропуск этого шага стоит недели: инструмент
выглядит установленным и рабочим ровно до первого настоящего запуска.

## 1. Аудит до установки

```
python tools/mcp_audit.py --server "<команда>" --tasks TASKS.md --i-trust-this-server
```

Скрипт покажет три вещи: сколько инструментов и во что они обходятся в **каждом**
запросе, какие из них не пересекаются с вашими задачами, какие умеют менять
состояние.

Если сервер не поднимается без ключей — не бросай затею: возьми список
инструментов из документации, сложи в JSON и передай `--from-json`.

Для репозитория скиллов вместо этого прочитай его состав: какие скиллы есть, что
каждый делает, каких сервисов требует.

## 2. Вопросы, без которых адаптация бессмысленна

- **Какие именно отчёты или ручки нужны?** Остальные вырезаем.
- **Что у вас всегда одинаково?** Атрибуция, период по умолчанию, счётчик, регион,
  разделение «поисковый трафик / весь сайт». Постоянное зашиваем в код,
  меняющееся оставляем параметром.
- **Есть ли доступ и ключи?** Нет — не ставим и предлагаем альтернативу.
- **Как проверим, что оно делает обещанное?** Это станет критерием приёмки.

Вопрос про атрибуцию задаётся не для порядка. Инструмент, в котором нет нужной
модели атрибуции, не решает задачу вообще — и выясняется это на результате, а не
на установке.

## 3. Три исхода

| Исход | Когда | Что делаем |
|---|---|---|
| Оставить как есть | разовая задача, инструментов немного | записываем в `ACCESS.md`, помечаем «только чтение» |
| Сузить | нужны две ручки из пятнадцати | свой тонкий слой; лишние определения перестают висеть в контексте |
| Заменить скриптом | регулярная задача, фиксированный набор данных | скрипт на `runtime.py`, постоянные параметры зашиты, сервер не нужен |

Выбор — по повторяемости задачи, а не по симпатии к инструменту.

## 4. После

Копируй **только выбранное**, с пометкой источника, даты и лицензии. Сразу
переписывай под сервисы человека: Метрика вместо GA, Вебмастер вместо GSC.

Запиши в `ACCESS.md`: что поставили, откуда, когда проверяли, к чему свели.

Проверь, что не осталось обращений к сервисам, которых нет в карте доступов:
именно так появляются инструменты, которые тянут сервис без доступа при задаче,
где он вообще не нужен.

Пиши на русском; имена инструментов, ссылки и код — как есть.
