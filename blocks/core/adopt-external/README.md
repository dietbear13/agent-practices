# Практика: ничего чужого — как есть

> Раздел доклада: 5 «Фреймворк: 3 пути взаимодействия с агентами», 6 «Почему куча MCP —
> плохо», 3.3 «Иллюзия переносимости автоматизации».

## Проблема

Чужую систему ставят целиком — и через три недели половина инструментов ни разу не
запускалась, а на простой вопрос агент тянет сервис без доступа. Определения всех
инструментов MCP висят в контексте при **каждом** запросе: пятнадцать ручек ради
двух нужных оплачиваются в каждом сообщении. А нужной атрибуции или отчёта в
инструменте может не оказаться вовсе — и выясняется это на результате.

## Как понять, что это про вас

- Подключено несколько MCP-серверов, и никто не скажет, какими инструментами из них
  реально пользовались за месяц.
- Подключённые MCP умеют писать, удалять или менять данные, хотя задачи только читают.
- Скиллы скопированы из чужих репозиториев без правки: упоминают GA вместо Метрики,
  GSC вместо Вебмастера, сервисы, к которым нет доступа.
- Регулярная задача решается через MCP, хотя набор данных каждый раз один и тот же.

## Минимальная правка

Перед установкой — аудит и сведение к одному из трёх исходов:

| Исход | Когда |
|---|---|
| Оставить как есть | разовые вопросы, инструментов немного; только чтение |
| Сузить | нужны две ручки из пятнадцати — свой тонкий слой |
| Заменить скриптом | регулярная задача, фиксированный набор данных |

Выбор — по повторяемости задачи, а не по симпатии к инструменту. Постоянные
параметры (атрибуция, период, счётчик, регион) зашиваются в код, меняющиеся
остаются параметром. Чужой MCP — только на чтение и без доступов к продакшену.

Это правило применимо и к самому этому репозиторию: из него берётся только то,
что закрывает конкретную проблему пользователя.

## Что можно взять отсюда

| Файл | Что это | Когда брать |
|---|---|---|
| [tools/mcp_audit.py](tools/mcp_audit.py) | поднимает сервер, забирает список инструментов, считает постоянную цену в контексте и находит опасные ручки. Ничего не вызывает | подключено много MCP или планируется новый |
| [skills/adapt-external/SKILL.md](skills/adapt-external/SKILL.md) | скилл разбора чужого MCP или репозитория скиллов: аудит → вопросы → три исхода | чужие инструменты ставят часто |

```
python mcp_audit.py --server "npx -y some-mcp-server" --i-trust-this-server
python mcp_audit.py --from-json tools_list.json
```

## Чего не делать

- Не ставить чужое «целиком, потом разберёмся»: не разбираются.
- Не оставлять обращения к сервисам, которых нет в карте доступов.
